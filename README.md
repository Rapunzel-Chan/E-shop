# Проект E-shop 

## Описание:

E-shop - виджет для создания ядра для интернет-магазина.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Rapunzel-Chan/E-shop
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:
1. Функции read_json и create_objects_from_json позволяют считывать данные о категориях и списках продуктов. 
2. Для цены класса Product был создан сеттер и геттер, чтобы получить список продуктов, с обновленной ценой. 
Переопределен метод __str__, который возвращает строку: Название продукта, X руб. Остаток: X шт.; 
Переопределен метод сложения __add__, который возвращает сумму произведений цены на количество у двух объектов.
3. Для класса Category создан новый метод add_product для добавления нового продукта в список.
Переопределен метод __str__, который возвращает строку: Название категории, количество продуктов: X шт.;
4. Для вспомогательного класса ProductIterator переопределены методы __iter__, __next__ для осуществления перебора
по списку продуктов.
5. Для родительского класса Product созданы классы-наследники Smartphone и LawnGrass с дополнительными атрибутами.
6. Создан абстрактный класс BaseProduct и абстрактный метод, а также класс PrintMixin для класса Product, чтобы выводить 
в консоль информацию о классе с параметрами. 
7. Создан общий абстрактный класс BaseSale и абстрактный метод для классов Category и Order, чтобы выводить 
в консоль информацию о проданном продукте. 
8. Дополнительная проверка на добавление товаров с нулевым количеством в Product.
9. Создана функция middle_price в Category для подсчета среднего арифметического.
10. Создан класс ZeroAddProduct для вывода сообщения о невозможности добавления товара с нулевым количеством.

## Тестирование:

1. Созданы тесты функций read_json и create_objects_from_json для проверки работоспособности функций и 
сформированных классов Product и Category;
2. Созданы тесты для проверки корректной работы со списком продуктов, в случае добавления нового продукта 
или увеличения количества уже существующего товара;
3. Созданы тесты для проверки корректной работы методов __str__, __add__, __iter__, __next__.
4. Созданы тесты для проверки работоспособности классов-наследников Smartphone и LawnGrass с дополнительными атрибутами.
5. Созданы тесты для PrintMixin, чтобы проверить работоспособность вывода данных о классе и его параметрах;
6. Созданы тесты для проверки корректной работы создания экземпляра класса Order.
7. Созданы тесты для проверки работоспособности функции middle_price.
8. Созданы тесты для отлавливания сообщений об успешном добавлении или ошибках добавления товаров 
в Category или Order.
