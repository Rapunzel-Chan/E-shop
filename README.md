# Проект ReportWidget (CourseWork1)

## Описание:

ReportWidget - виджет для шифрования номеров банковских карт и счетов, для сортировки по описанию и категориям банковских операций клиента.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Rapunzel-Chan/homework.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:
1. Функции get_greeting и get_time_for_greeting необходимы для определения текущего времени и возврата соответствующего 
приветствия;
2. Функция get_filtered_data фильтрует транзакции с первого числа месяца введенной конечной даты до введенной даты;
3. Функция get_card_info возвращает сумму трансакций в рублях с учетом курса валют;
4. Функция get_top_transactions возвращает топ-5 транзакций по сумме платежа в рублях;
5. Функции get_currency_rates_list, get_exchange_rates, get_stock_prices и get_stock_prices_list возвращает курс валют 
и стоимость акций, а также формирует списки с ними;
6. Функции read_xlsx_transactions и load_user_settings возвращают список транзакций и настроек пользователя;
7. Функция simple_search позволяет искать список транзакций по графе "категории" и "описанию";
8. Функция spending_by_workday позволяет отфильтровать и посчитать сумма затрат в зависимости от типа дня: 
9. Функция main собирает всю функциональность виджета.



## Тестирование:

1. Созданы тесты функций get_greeting, get_filtered_data, get_card_info, get_top_transactions, get_currency_rates_list, 
get_stock_prices_list на правильную работу функций, также проводилась проверка устойчивости к ошибкам, применялся
freeze_time, чтобы не было привязки к загруженному списку транзакций, параметризация и мокирование обращения к внешним 
функциям и источникам;
2. Созданы тесты функций get_time_for_greeting, read_xlsx_transactions, get_exchange_rates, get_stock_prices, 
load_user_settings на правильную работу сортировки в зависимости от указанного параметра, в том числе с применением 
patch и MagicMock; 
3. Созданы тесты функции simple_search для проверки устойчивости к ошибкам с использованием фикстур;
4. Созданы тесты функции spending_by_workday для проверки работоспособности с использованием параметризации и фикстур.
5. Функция main была исключена из тестирования и покрытия.
